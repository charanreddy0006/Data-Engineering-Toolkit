# Automotive Governed Data Product

## Purpose
Design a certified vehicle telemetry data product.

## Product Contract

Name: Certified Vehicle Telemetry

Owner: Connected Vehicle Domain

Purpose: Approved engineering, fleet, and analytics use.

Inputs: telemetry events.

Outputs: validated and documented telemetry tables.

Controls: classification, quality checks, lineage, access approval, retention,
schema compatibility, operational monitoring.

## Definition of Done

A data product is not finished when its table exists. It is finished when consumers
can discover it, understand it, trust it, access it appropriately, and know how it
will change.
