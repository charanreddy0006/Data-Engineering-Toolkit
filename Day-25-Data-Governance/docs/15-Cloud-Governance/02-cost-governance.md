# Data Cost Governance

## Purpose
Treat cloud cost as a governed operational dimension.

## Cost Controls

- tag datasets/workloads by owner
- measure storage and compute
- define retention
- detect idle resources
- monitor expensive queries/jobs
- assign budgets/alerts
- review cost per data product

## Automobile Example

Connected-vehicle telemetry can produce enormous volumes. Governance should prevent
unnecessary duplicate copies and unlimited retention.
