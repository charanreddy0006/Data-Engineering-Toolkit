# Automotive Data Classification

## Purpose
Apply classification thinking to connected-vehicle data.

## Examples

| Asset | Example Risk | Possible Class* |
|---|---|---|
| Public model brochure | low | PUBLIC |
| Internal production KPI | medium | INTERNAL |
| Supplier commercial data | business-sensitive | CONFIDENTIAL |
| Customer-linked location | potentially high | RESTRICTED |
| Raw diagnostic security material | potentially high | RESTRICTED |

*Classification must follow the organization's actual policy and applicable law.

## Important Distinction

A technical field name alone does not determine classification. Context, linkage,
purpose, jurisdiction, and policy matter.
