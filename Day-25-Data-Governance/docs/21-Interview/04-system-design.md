# Governance System Design Interview

## Purpose
Design governance for a large data platform.

## Expected Components

```text
Identity/IAM
Catalog
Business Glossary
Lineage
Policy Engine
Data Quality
Audit
Workflow/Approval
Data Platforms
Monitoring
```

## Interview Strategy

Start with requirements and risk. Define domains and ownership. Then design metadata,
catalog, policy enforcement, lineage, access, quality, monitoring, and evidence.
Do not start by naming a tool.
