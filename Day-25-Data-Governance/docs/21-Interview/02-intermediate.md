# Intermediate Interview Questions

## Purpose
Practice practical architecture and operating-model questions.

## Questions

1. Centralized vs federated governance?
2. How would you create a RACI?
3. How does a catalog support governance?
4. How would you govern a critical dataset?
5. How would you handle a schema-breaking change?
6. How do RBAC and ABAC differ?
7. How do lineage and impact analysis relate?
8. What governance KPIs would you track?
9. How would you manage an exception?
10. How would you govern master data?
