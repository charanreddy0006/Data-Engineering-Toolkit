# Beginner Interview Questions

## Purpose
Practice foundational governance questions.

## Questions

1. What is data governance?
2. Why is governance needed?
3. What is a data owner?
4. What is a data steward?
5. What is metadata?
6. What is a business glossary?
7. What is a data catalog?
8. What is data lineage?
9. What is data classification?
10. What is data retention?

## Answer Pattern

For each answer: define it -> explain why -> give one example -> mention a control.
