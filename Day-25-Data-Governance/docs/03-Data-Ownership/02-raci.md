# RACI for Data Governance

## Purpose
Use RACI to make decision rights explicit.

## RACI

- **R — Responsible:** performs the work.
- **A — Accountable:** owns the outcome/decision.
- **C — Consulted:** provides input.
- **I — Informed:** kept aware.

## Example

| Activity | Owner | Steward | Custodian | Security |
|---|---|---|---|---|
| Classification | A | R | C | C |
| Catalog metadata | A | R | C | I |
| Access implementation | A | C | R | C |
| Pipeline operation | I | C | R | I |
| Definition change | A | R | C | C |
