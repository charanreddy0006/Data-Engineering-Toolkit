# Quality Governance

## Purpose
Connect data quality controls to accountable ownership.

## Governance Questions

- Which dimensions matter?
- What threshold is acceptable?
- Who owns remediation?
- How quickly must issues be fixed?
- Which consumers are affected?
- What happens when quality falls below threshold?

## Dimensions

Common dimensions include:
- completeness
- validity
- accuracy
- consistency
- uniqueness
- timeliness

## Automobile Example

A vehicle telemetry product might require valid VIN references, non-null event time,
reasonable sensor ranges, and freshness within an agreed target.
