# Governance KPIs

## Purpose
Measure whether governance is actually working.

## Example KPIs

- % critical assets with owners
- % critical assets cataloged
- % critical assets classified
- % critical assets with lineage
- metadata freshness
- access-review completion
- policy exception aging
- quality issue resolution time
- data contract compliance
- retention-policy execution rate

## Avoid Vanity Metrics

Counting cataloged tables alone is weak. Pair activity metrics with outcome metrics,
such as reduced incident impact, improved discovery time, and fewer unauthorized
access findings.
