# Data Governance Lifecycle

## Purpose
Understand governance as a continuous lifecycle.

## Lifecycle

```text
Identify -> Classify -> Assign Owner -> Define Policy
     -> Catalog -> Control Access -> Monitor
     -> Review Exceptions -> Improve -> Repeat
```

## Example

A new EV battery dataset is onboarded. It is classified, assigned to an owner,
documented in the catalog, given retention/access rules, monitored for quality and
policy violations, and periodically reviewed.

## Key Idea

Governance is continuous. A dataset can change classification, owner, consumers,
retention, or business meaning over time.
