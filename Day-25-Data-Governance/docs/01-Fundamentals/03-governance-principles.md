# Data Governance Principles

## Purpose
Learn principles that can guide practical design.

## Core Principles

1. Accountability — every critical data domain has accountable roles.
2. Transparency — users can understand definitions and policies.
3. Discoverability — approved data should be easy to locate.
4. Trust — quality expectations are explicit and measurable.
5. Least privilege — access is no broader than necessary.
6. Purpose limitation — data is used for legitimate defined purposes.
7. Traceability — important transformations and decisions are auditable.
8. Change control — breaking changes are managed before release.
9. Automation — controls should be machine-enforced where practical.
10. Business value — governance should enable useful data products.

## Design Test

For every proposed control ask:

`Does it reduce a real risk, clarify accountability, or improve data value?`

If not, reconsider whether the control adds useful governance.
