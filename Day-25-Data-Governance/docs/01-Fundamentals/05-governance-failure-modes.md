# Data Governance Failure Modes

## Purpose
Recognize why governance programs fail.

## Failure Modes

- Governance exists only in documents.
- No executive sponsorship.
- Roles exist on paper but have no decision rights.
- Policies are impossible to operationalize.
- Metadata is stale.
- Catalog becomes a static inventory.
- Quality problems are reported but nobody owns remediation.
- Security controls are disconnected from business classification.
- Every dataset gets the same governance burden.
- Teams bypass governance because approved paths are too slow.

## Better Pattern

Use risk-based governance. High-risk data receives stronger controls while low-risk
data follows lighter processes.
