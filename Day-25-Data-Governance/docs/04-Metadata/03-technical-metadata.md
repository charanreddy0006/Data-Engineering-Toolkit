# Technical Metadata

## Purpose
Learn what engineers need to govern physical data assets.

## Typical Fields

| Metadata | Example |
|---|---|
| System | telemetry-platform |
| Dataset | vehicle_events |
| Column | battery_soc |
| Type | decimal |
| Owner | connected-vehicle domain |
| Location | lakehouse curated zone |
| Partition | event_date |
| Update frequency | near-real-time |
| Classification | internal |

## Automation

Technical metadata should be harvested automatically where possible. Manual entry
should focus on information machines cannot reliably infer, such as business meaning
and accountability.
