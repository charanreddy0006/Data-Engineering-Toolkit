# Data Quality Dimensions

| Dimension | Question |
|---|---|
| Completeness | Is required data present? |
| Accuracy | Does it represent reality? |
| Consistency | Does it agree across representations? |
| Validity | Does it satisfy allowed rules? |
| Uniqueness | Are supposed-unique values duplicated? |
| Integrity | Are relationships valid? |
| Timeliness | Is it available when required? |
| Freshness | How recently was it updated? |
| Coverage | Are expected entities/periods represented? |

Remember:

```text
Valid != Accurate
Complete != Correct
Fresh != Consistent
Schema-valid != Business-valid
```
