# Production Checklist

Before production:

- [ ] Critical data elements defined
- [ ] Schema and semantics documented
- [ ] Rules and thresholds defined
- [ ] Owners assigned
- [ ] Quarantine behavior defined
- [ ] Alert routing defined
- [ ] Replay/backfill defined
- [ ] CI tests added
- [ ] Runbook documented

During production:

- [ ] freshness
- [ ] volume
- [ ] validity
- [ ] duplicates
- [ ] coverage
- [ ] drift

After incidents:

- [ ] root cause
- [ ] recovery
- [ ] validation
- [ ] prevention
- [ ] owner
