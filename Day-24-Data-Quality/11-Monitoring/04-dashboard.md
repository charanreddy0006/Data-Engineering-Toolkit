# Quality Dashboard

A quality dashboard should answer:

1. Is data healthy now?
2. Is it improving or degrading?
3. Which dataset is affected?
4. Which rule failed?
5. Who owns it?
6. What is the business impact?

Suggested panels:

```text
Overall quality
Quality by dataset
Quality by dimension
Freshness
Volume
Top failing rules
Open incidents
```

Automobile panels can include:

- telemetry validity
- fleet coverage
- EV SOC validity
- orphan events
- duplicate rate
- latest partition
