# Feature Naming Standard

Use names that communicate:
- metric
- time window
- entity where needed

Examples:
```text
distance_km_30d
fault_count_24h
service_count_90d
battery_soc_latest
energy_per_100km_30d
```

Avoid:
```text
f1
feature_x
avg1
temp_feature
```

Keep naming consistent across teams.
