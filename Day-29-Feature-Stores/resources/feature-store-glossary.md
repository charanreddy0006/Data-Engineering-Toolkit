# Glossary

**Feature:** Input variable used by an ML model.

**Entity:** Subject for which a feature is defined.

**Offline Store:** Historical feature storage for training and analysis.

**Online Store:** Low-latency serving store.

**Feature View:** Logical grouping of related feature definitions.

**Materialization:** Making computed features available in a serving store.

**Point-in-Time Correctness:** Ensuring features only use information available by the prediction time.

**Training-Serving Skew:** Difference between training and production feature computation.

**Freshness:** Age of the latest valid feature value.

**Feature Drift:** Change in feature distribution over time.
