# Kubernetes Interview — Beginner

## What is Kubernetes?

A platform for orchestrating containerized workloads across clusters.

## What is a Pod?

The smallest deployable Kubernetes unit containing one or more containers.

## What is a Deployment?

A controller for replicated stateless workloads and rolling updates.

## What is a Service?

A stable network abstraction that targets matching Pods.

## What is a Namespace?

A logical resource grouping and isolation mechanism.

## What is ConfigMap?

An object for non-sensitive configuration.

## What is Secret?

An object intended for sensitive configuration and credentials, requiring proper security controls.

## What is Job?

A run-to-completion workload.

## What is CronJob?

A resource that creates Jobs on a schedule.

## What is kubectl?

A command-line client for the Kubernetes API.

## What is etcd?

A key-value store used for Kubernetes cluster state.

## What is kubelet?

The node agent responsible for managing Pods on a node.
