# DevOps vs CI/CD

DevOps is broader than CI/CD.

```text
DevOps
├── CI/CD
├── Infrastructure as Code
├── Observability
├── Collaboration
├── Reliability
└── Security
```

CI/CD is the automation around integration, testing, delivery and deployment.

## Data engineering

DevOps practices can apply to:

- ETL,
- orchestration,
- cloud infrastructure,
- data quality,
- incident response,
- platform operations.

CI/CD is an important mechanism, not the complete DevOps model.
