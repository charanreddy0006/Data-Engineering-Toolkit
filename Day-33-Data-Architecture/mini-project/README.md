# 🧪 Mini Project — Enterprise Vehicle Analytics Architecture

## Goal
Design a platform for vehicle sales, service, warranty and telemetry that supports BI, ML and live operational use cases.

## Requirements
- historical analytics
- real-time fault alerts
- ML feature support
- security
- quality
- monitoring
- disaster recovery
- controlled cost

## Deliverables
1. Context diagram
2. Logical architecture
3. Physical architecture
4. Data flow
5. Batch/streaming decision
6. Storage strategy
7. Security boundary
8. RPO/RTO
9. Cost strategy
10. ADRs
