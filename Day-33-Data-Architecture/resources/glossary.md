# Data Architecture Glossary

**Data Architecture:** structure and behavior of systems that create, move, store, transform and serve data.

**Data Product:** managed data interface for defined consumers.

**Lakehouse:** scalable analytical architecture built over lake-style storage with managed table capabilities.

**Medallion:** Bronze/Silver/Gold organization pattern.

**Lambda:** batch + speed architecture.

**Kappa:** streaming-centric architecture using replay.

**Data Mesh:** domain-oriented data ownership and data products.

**Data Fabric:** metadata/integration/governance-oriented approach across distributed data.

**RPO:** acceptable data loss measured in time.

**RTO:** target recovery time.
