# 25. Data Mesh

Data mesh is a domain-oriented approach emphasizing data ownership and data products.

## Common principles
1. Domain ownership
2. Data as a product
3. Self-serve platform
4. Federated governance

## Example
```text
Vehicle Domain ─┐
Service Domain ─┼→ Governed Data Products
Warranty Domain ┘
```

## Benefits
Domain expertise stays close to the data.

## Challenges
Needs strong standards, platform capabilities and governance.

## Automobile
Vehicle, Service and Warranty domains can publish reusable products to enterprise analytics.
