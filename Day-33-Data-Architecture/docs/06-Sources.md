# 6. Source Layer

Sources create or provide data.

## Examples
- OLTP databases
- APIs
- files
- SaaS
- IoT devices
- event streams

## Record
For each source document:
- owner
- schema
- update frequency
- business meaning
- quality
- latency
- retention

## Automobile Sources
Vehicle telemetry, dealer sales, service orders, warranty, manufacturing, inventory and charging.

Source ownership should remain clear even when data is copied into a central platform.
