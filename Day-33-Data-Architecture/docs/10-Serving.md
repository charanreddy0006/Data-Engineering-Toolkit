# 10. Serving Layer

Serving provides data in a form optimized for consumers.

## Examples
```text
BI → warehouse
ML → feature store
Application → API / low-latency store
Search → search index
```

## Principle
Optimize serving for the consumer.

## Automobile
A fleet dashboard needs analytical aggregates, while a vehicle-risk API needs fresh low-latency values.

One store does not have to satisfy every workload.
