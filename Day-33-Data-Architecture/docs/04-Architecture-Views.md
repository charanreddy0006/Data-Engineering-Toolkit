# 4. Architecture Views

Use multiple views.

## Context
Systems and actors.

## Logical
Responsibilities and relationships.

## Physical
Actual infrastructure and services.

## Deployment
Where components run.

## Data Flow
How records move and change.

## Security
Trust boundaries and access paths.

```text
Context → Logical → Physical → Deployment
```

A business stakeholder may need a simple context diagram, while engineers need physical and deployment details.
