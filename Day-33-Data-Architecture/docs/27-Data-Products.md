# 27. Data Products

A data product is a managed data interface built for defined consumers.

## Example
**Vehicle Health Product**

Contains:
- vehicle ID
- latest state
- fault metrics
- trip aggregates
- freshness
- quality status

## Contract
```text
Owner
Schema
Definition
SLA
Quality
Security
Support
```

## Automobile
A vehicle-health product can serve fleet teams, service teams and predictive-maintenance models.
