# 39. Architecture Documentation

A production design should be understandable to technical and business stakeholders.

## Include
- context
- requirements
- logical architecture
- physical architecture
- data flow
- interfaces
- security
- operations
- ownership
- failure cases
- cost
- assumptions

## Diagram levels
```text
Context → Logical → Physical → Deployment
```

## Automobile
Document separate views for connected vehicles, streaming, warehouse, ML, BI and security boundaries.
