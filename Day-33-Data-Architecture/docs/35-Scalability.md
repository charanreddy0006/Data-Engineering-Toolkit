# 35. Scalability Architecture

## Vertical
Use larger resources.

## Horizontal
Add more instances.

## Partitioning
Distribute data and work.

## Sharding
Distribute datasets across nodes.

## Bottlenecks
```text
Source → Network → Compute → State → Storage → Consumer
```

Measure before scaling.

## Automobile
Fleet growth increases event volume, storage, network traffic and downstream query load. Capacity planning must cover every layer.
