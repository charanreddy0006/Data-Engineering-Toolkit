# 13. Data Lake Architecture

A data lake stores large volumes of diverse data on scalable storage.

```text
Raw
 ↓
Cleaned
 ↓
Curated
```

## Strengths
- flexible formats
- large-scale storage
- separation of storage and compute

## Challenges
- governance
- discoverability
- quality
- schema management

## Automobile
Keep raw telemetry in the lake while producing curated trip and vehicle-health datasets for downstream use.
