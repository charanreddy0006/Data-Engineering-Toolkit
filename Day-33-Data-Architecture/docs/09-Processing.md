# 9. Processing Layer

Processing transforms data into useful outputs.

## Batch
Daily transformations, historical calculations and large aggregations.

## Streaming
Event-time processing, live aggregations and alerts.

## Technologies
SQL, Python, Spark, Flink and other engines.

Choose from:
- scale
- latency
- complexity
- team capability
- operational needs

## Automobile
Telemetry can be processed continuously while service analytics are transformed daily.
