# 26. Data Fabric

Data fabric is an architecture approach focused on integration, metadata, governance and access across distributed environments.

```text
DB + Lake + Warehouse + SaaS + Streams
                 ↓
       Metadata / Governance
                 ↓
          Integrated Access
```

## Focus
- metadata
- lineage
- interoperability
- governance
- automation

## Automobile
Manufacturing, dealer and connected-vehicle systems can remain distributed while enterprise metadata connects them.
