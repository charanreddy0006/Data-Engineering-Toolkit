# 33. Streaming Monitoring

## Metrics
- events/sec
- consumer lag
- processing latency
- error rate
- state size
- output freshness
- checkpoint duration

## Example
```text
Input rate: 85k events/s
Lag: 2.4s
p95 latency: 180ms
Freshness: 3s
```

## Alerts
Use actionable thresholds for lag, latency, failures, state growth and output freshness.
