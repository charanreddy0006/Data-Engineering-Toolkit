# Streaming Design Checklist

1. What event is produced?
2. What is the event rate?
3. What latency is required?
4. What is the key?
5. What is the partition strategy?
6. What ordering is required?
7. What schema is used?
8. What is event time?
9. What window is required?
10. How are late events handled?
11. Is state required?
12. How are duplicates handled?
13. What delivery semantics are required?
14. How does recovery work?
15. How will lag be monitored?
16. What security is required?
17. What is the cost model?
