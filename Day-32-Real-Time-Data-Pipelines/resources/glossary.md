# Glossary

**Event:** record describing something that happened.

**Producer:** publishes events.

**Consumer:** reads events.

**Topic:** logical event stream.

**Partition:** parallel stream segment.

**Consumer Group:** consumers sharing work.

**Offset:** progress position.

**Event Time:** time the event occurred.

**Processing Time:** time it was processed.

**Watermark:** event-time progress indicator.

**Window:** time-based grouping.

**State:** information retained across events.

**Backpressure:** processing cannot keep up with input.

**Consumer Lag:** processing progress behind the source.
