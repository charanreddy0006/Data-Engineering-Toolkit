# ⚡ Day 32 — Real-Time Data Pipelines

A practical Data Engineering module for designing **real-time, event-driven and low-latency data pipelines**.

## Learn
- Streaming fundamentals
- Event-driven architecture
- Producers, consumers, topics and partitions
- Consumer groups and offsets
- Event schemas
- Event time and processing time
- Windows and watermarks
- Late events and stateful processing
- Stream joins and aggregations
- Deduplication and idempotency
- Delivery guarantees
- Checkpointing and recovery
- Backpressure and scaling
- Kafka, Spark Structured Streaming and Flink
- Streaming ETL
- Real-time feature pipelines
- Real-time dashboards
- Monitoring, security, cloud architecture and cost

## Core Flow

```text
Event Source
    ↓
Event Broker
    ↓
Stream Processor
    ↓
Validation / Enrichment / Aggregation
    ↓
Real-Time Store / Feature Store / Lake
    ↓
Dashboard / ML / Alerts / Applications
```

## Automobile Focus 🚗
Connected-vehicle telemetry, vehicle faults, GPS, trips, EV charging, battery signals and live fleet operations.
