# Mini Project — Automobile Service BI

## Objective
Build a small analytical model for dealer service performance.

## Questions
1. What is total service revenue?
2. Which dealer has the most orders?
3. What is average repair order value?
4. Which model has the highest service cost?
5. How does revenue change month over month?

## Steps
1. Create schema.
2. Load sample data.
3. Run analytical SQL.
4. Validate KPI calculations.
5. Connect a BI tool.
6. Build an executive page.
7. Add dealer filtering.
8. Document refresh and security.

## Deliverables
- Star schema
- KPI dictionary
- SQL queries
- Dashboard
- Architecture diagram
- README
