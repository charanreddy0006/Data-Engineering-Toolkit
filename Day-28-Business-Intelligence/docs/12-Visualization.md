# 12. Data Visualization

## Choosing a Chart

| Question | Suitable Visual |
|---|---|
| Trend over time | Line |
| Compare categories | Bar |
| Part-to-whole | Stacked bar / limited pie use |
| Distribution | Histogram |
| Relationship | Scatter |
| Geographic pattern | Map |
| KPI value | Card |

## Common Mistakes
- 3D charts
- Too many colors
- Truncated axes without explanation
- Excessive decoration
- Mixing unrelated metrics
- Using pie charts for many categories

## Automobile Examples
Line chart → monthly vehicle sales.

Bar chart → service revenue by dealer.

Scatter plot → vehicle mileage vs maintenance cost.

Map → service volume by region.

## Accessibility
Use readable fonts, meaningful labels and sufficient contrast. Do not communicate meaning through color alone.
