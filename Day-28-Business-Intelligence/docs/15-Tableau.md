# 15. Tableau

## Overview
Tableau is a BI and visual analytics platform focused strongly on interactive visual exploration.

## Core Concepts
- Data sources
- Worksheets
- Dashboards
- Stories
- Dimensions
- Measures
- Calculated fields
- Filters
- Parameters
- Extracts

## Workflow
```text
Connect → Prepare → Build Worksheet → Combine Dashboard → Publish
```

## Automobile Example
Create a fleet dashboard with:
- Vehicle count
- Average daily distance
- Service cost
- Regional utilization
- Model-level warranty claims

## Important Learning Point
A BI tool does not replace data modeling. Strong dashboards still depend on trustworthy analytical data.
