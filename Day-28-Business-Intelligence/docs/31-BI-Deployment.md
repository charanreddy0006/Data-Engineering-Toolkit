# BI Deployment

## Environment Pattern
```text
Development → Test → Production
```

## Version Control
Store:
- SQL
- semantic definitions
- KPI dictionary
- documentation
- infrastructure/configuration where supported

## Deployment Checklist
- SQL tested
- Data quality tests passed
- KPI reconciliation completed
- Security tested
- Performance checked
- Refresh configured
- Owner documented
- Rollback plan available

## Production Principle
A dashboard is a production data product when people depend on it for business decisions. Treat it accordingly.
