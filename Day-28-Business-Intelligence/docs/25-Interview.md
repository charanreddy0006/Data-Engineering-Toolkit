# 25. BI Interview Questions

## Beginner
1. What is Business Intelligence?
2. What is a dashboard?
3. What is a KPI?
4. What is a dimension?
5. What is a fact table?
6. What is grain?
7. What is OLAP?
8. What is a star schema?

## Intermediate
1. Explain additive and non-additive measures.
2. Explain semantic layers.
3. What is row-level security?
4. How do you optimize a slow dashboard?
5. Why use a date dimension?
6. What is incremental refresh?
7. Explain governed self-service BI.
8. How do you prevent double counting?

## Advanced
1. Design BI architecture for billions of telemetry events.
2. How would you handle late-arriving facts?
3. How would you design a metric governance process?
4. How would you monitor dashboard freshness?
5. How would you isolate tenant data in embedded BI?

## Scenario
A vehicle dashboard shows service revenue that is 30% higher than the finance report. Investigate:
1. Metric definition
2. Grain
3. Join duplication
4. Filters
5. Date logic
6. Currency/tax handling
7. Data freshness
8. Source reconciliation

## Interview Formula
Always explain:
**Business requirement → data → model → metric → security → performance → monitoring.**
