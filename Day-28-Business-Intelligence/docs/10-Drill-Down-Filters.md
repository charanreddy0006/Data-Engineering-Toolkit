# 10. Drill-Down and Filters

## Drill-Down
Moves from a high-level view to more detailed levels.

Example:
```text
Year
 ↓
Quarter
 ↓
Month
 ↓
Day
```

## Automobile Drill Path
```text
Country
 ↓
State
 ↓
Dealer
 ↓
Service Center
 ↓
Vehicle
```

## Filters
Common filter types:
- Report filter
- Page filter
- Visual filter
- User-level filter
- Date filter

## Slicers
Interactive controls allowing users to select values such as:
- Model
- Dealer
- Region
- Fuel type
- Vehicle type

## Best Practices
- Keep filters understandable.
- Avoid dozens of slicers.
- Provide a reset option.
- Show active filter context.
- Avoid hidden filters that change KPI meaning.

## Drill-Through
A user can move from a summary dashboard into a detail page while carrying the selected context.
