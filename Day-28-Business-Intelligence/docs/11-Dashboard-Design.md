# 11. Dashboard Design

## Start With Questions
Do not begin by choosing charts. Begin with business questions.

Example:
1. How are sales performing?
2. Which dealers need attention?
3. Are service costs increasing?
4. Which models have warranty issues?

## Dashboard Hierarchy
```text
Title / Context
      ↓
Primary KPIs
      ↓
Trends
      ↓
Breakdowns
      ↓
Detailed table / action
```

## Executive Automobile Dashboard
KPIs:
- Vehicles sold
- Revenue
- Service revenue
- Warranty rate
- Active connected vehicles

Charts:
- Monthly sales trend
- Revenue by region
- Warranty rate by model
- Dealer service performance

## Dashboard Checklist
- Clear title
- Correct units
- Consistent definitions
- Limited visual clutter
- Useful filters
- Visible last refresh time
- Actionable insights
