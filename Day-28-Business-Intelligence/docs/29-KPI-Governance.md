# KPI Governance

A KPI is not only a formula. It needs ownership and context.

## KPI Contract
```text
Name
Description
Business Owner
Technical Owner
Formula
Numerator
Denominator
Grain
Filters
Time Zone
Currency
Source
Refresh
Target
Exceptions
Version
```

## Example
Warranty Claim Rate must specify whether the denominator is:
- all vehicles,
- eligible vehicles,
- vehicles sold during a period,
- or vehicles within warranty.

Changing the denominator changes the meaning of the KPI.

## Governance Workflow
Propose → Review → Approve → Implement → Test → Publish → Monitor.
