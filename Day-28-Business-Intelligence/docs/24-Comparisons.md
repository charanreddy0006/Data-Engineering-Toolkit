# 24. BI Comparisons

## Power BI vs Tableau vs Looker

| Area | Power BI | Tableau | Looker |
|---|---|---|---|
| Strength | Microsoft ecosystem | Visual exploration | Central modeling |
| Modeling | Semantic models | Data sources | LookML |
| Calculation | DAX | Calculations | LookML/SQL |
| Cloud integration | Strong Microsoft integration | Broad ecosystem | Strong Google Cloud integration |
| Best fit | Enterprise Microsoft environments | Visual analytics | Governed model-centric analytics |

These are broad architectural characteristics; actual suitability depends on organization, data stack, skills, licensing and requirements.

## BI vs Data Engineering
Data engineering focuses on reliable data systems and pipelines. BI focuses on consuming trusted data for analysis and decisions. They overlap heavily in modern platforms.

## Dashboard vs Report
A dashboard usually emphasizes a concise monitoring view. A report can contain multiple pages and deeper analysis.

## Metric vs KPI
A metric is a measurable value. A KPI is a metric selected and governed as an indicator of an important business objective.
