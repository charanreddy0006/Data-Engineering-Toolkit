# Data Security Production Checklist

## Purpose
Use before releasing a critical data product.

## Checklist

- [ ] Asset classified
- [ ] Owner identified
- [ ] Human access scoped
- [ ] Workload identity scoped
- [ ] Encryption enabled
- [ ] TLS used where required
- [ ] Secrets externalized
- [ ] Network restricted
- [ ] Audit enabled
- [ ] Monitoring configured
- [ ] Backup protected
- [ ] Recovery tested
- [ ] Access review scheduled
