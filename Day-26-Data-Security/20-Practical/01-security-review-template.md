# Security Review Template
## Asset
Name, owner, classification, business purpose.
## Threats
List realistic confidentiality, integrity, availability, and abuse scenarios.
## Access
Human identities, workloads, permissions, approval, review.
## Data
Encryption, masking, minimization, retention.
## Platform
Network, configuration, patching, dependencies.
## Operations
Audit, monitoring, incident response, recovery.
## Evidence
Links to tests, logs, approvals, scans, and configuration evidence.
