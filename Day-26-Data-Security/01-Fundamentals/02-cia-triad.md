# CIA Triad

## Purpose
CIA describes confidentiality, integrity, and availability.

## Confidentiality

Only authorized identities should see information.

## Integrity

Data and security configurations should not be changed improperly.

## Availability

Authorized systems should receive required data/services when needed.

## Example

Exposed customer-linked location is a confidentiality failure; altered telemetry is an integrity failure; an unavailable operational platform is an availability failure.
