# Automotive Security Incident Runbook
## Scenario
A telemetry credential may have been exposed.
## Steps
1. Start the approved incident process.
2. Identify credential and affected systems.
3. Revoke/rotate according to procedure.
4. Review audit evidence for use.
5. Identify affected data/time window.
6. Restrict suspicious access.
7. Preserve evidence.
8. Involve appropriate security/privacy/legal functions.
9. Recover services.
10. Validate controls.
11. Document lessons and improvements.
## Never
Do not publish secrets in tickets, delete evidence, or reuse a compromised credential.
