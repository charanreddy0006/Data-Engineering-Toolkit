# Day 26 Roadmap — Data Security

1. Fundamentals: CIA, principles, threat modeling, attack surface, defense in depth.
2. Identity: authentication, authorization, IAM, RBAC, ABAC, least privilege, MFA, workload identities.
3. Cryptography: encryption, TLS, hashing, salting, HMAC, signatures, keys, KMS.
4. Data protection: masking, tokenization, pseudonymization, DLP, minimization, non-production data.
5. Network security: segmentation, private connectivity, firewalls, zero trust.
6. Platform security: databases, row/column controls, object storage, lakehouse, backups.
7. Pipeline security: ETL/ELT, Airflow, Spark, Kafka, APIs, secrets.
8. Operations: logging, auditing, anomaly detection, incident response, recovery.
9. DevSecOps/cloud: dependencies, containers, CI/CD, IAM, storage, networks.
10. Automobile capstone: telemetry, VIN, location, EV data, secure pipeline, incident runbook.
