## How to Use Resources

Do not read everything at once.

Use documentation when implementing a real problem.

Example:

```text
Learning SCD
   ↓
Understand concept here
   ↓
Implement SQL
   ↓
Read warehouse-specific documentation
   ↓
Test behavior
```
