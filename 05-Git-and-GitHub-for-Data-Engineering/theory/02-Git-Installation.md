# Git Installation

## Introduction

Git can be installed on Windows, Linux, and macOS.

After installation, Git commands can be executed from a terminal.

## Windows

Git can be installed using Git for Windows.

After installation, Git can be used from:

- Git Bash
- PowerShell
- Command Prompt
- VS Code terminal

Verify installation:

```bash
git --version
