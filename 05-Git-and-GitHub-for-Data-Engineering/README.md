# Git & GitHub for Data Engineering

Git is a distributed version control system used to track changes in source code, scripts, configuration, and documentation.

GitHub provides a platform for hosting Git repositories, collaborating with teams, reviewing code, and automating development workflows.

For Data Engineers, Git is important because data pipelines contain many scripts, SQL files, configurations, infrastructure definitions, and documentation that must be version controlled.
