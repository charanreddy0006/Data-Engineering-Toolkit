# File Format Cheat Sheet

```text
CSV      -> simple flat interchange
TSV      -> tabular interchange with tabs
JSON     -> nested API/document data
JSONL    -> line-oriented events
XML      -> enterprise hierarchical exchange
YAML     -> configuration
Avro     -> schema-driven serialization
Parquet  -> analytical columnar storage
ORC      -> analytical columnar storage
XLSX     -> spreadsheet exchange
```
