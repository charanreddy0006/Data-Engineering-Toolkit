# Project 3 — File Format Benchmark

Create equivalent datasets in:

```text
CSV
JSONL
Parquet
ORC
```

Run:

1. full read;
2. two-column read;
3. filtered read;
4. group-by;
5. storage-size measurement.

Record:

```text
engine
hardware
dataset size
compression
runtime
bytes read
CPU
memory
file count
```

Do not call a format faster without controlled measurement.
