# Further Learning

Study these topics after completing the module:

1. Parquet encoding and metadata.
2. ORC internals.
3. Avro schema compatibility.
4. Apache Arrow.
5. Object-storage data layouts.
6. Lakehouse table formats.
7. Data contracts.
8. Schema registries.
9. Benchmarking methodology.
10. File compaction strategies.

## Practice progression

```text
read CSV
  ↓
validate CSV
  ↓
write Parquet
  ↓
partition
  ↓
compress
  ↓
inspect metadata
  ↓
benchmark
  ↓
introduce schema change
  ↓
recover from bad data
```

Then repeat the exercise with automobile telemetry.
