1. Introduction
2. Core concepts
3. Architecture
4. Installation
5. API / SQL reference
6. Performance
7. Security
8. Deployment
9. Troubleshooting

## 38. Documentation Best Practice

Use official documentation to verify:

- Syntax
- Configuration
- Version compatibility
- Security settings
- Deployment requirements
- API behavior

## 39. Version Awareness

Technology documentation changes.

Always check the documentation version relevant to the installed software.

Example:

```text
Spark 3.x
```

should be matched with the correct Spark documentation.
