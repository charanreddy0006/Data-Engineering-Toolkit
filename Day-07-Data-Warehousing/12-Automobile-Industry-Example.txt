# Data Warehousing - Automobile Industry Example

## 1. Use Case

Design a data warehouse for an automobile company.

The company collects data from:

- Vehicle sensors
- Sales systems
- Service centers
- Dealers
- Customers
- Warranty systems

## 2. Architecture

```text
Vehicle Sensors
       |
       v
Kafka
       |
       v
Data Lake
       |
       v
Spark
       |
       v
Data Warehouse
       |
       v
Power BI
```

## 13. Revenue KPI

```sql
SELECT
    SUM(amount) AS total_revenue
FROM fact_sales;
```

## 14. Service Cost KPI

```sql
SELECT
    SUM(cost) AS total_service_cost
FROM fact_service;
```

## 15. Model Performance

```sql
SELECT
    v.model,
    SUM(s.amount) AS revenue
FROM fact_sales s
JOIN dim_vehicle v
    ON s.vehicle_key = v.vehicle_key
GROUP BY v.model;
```
