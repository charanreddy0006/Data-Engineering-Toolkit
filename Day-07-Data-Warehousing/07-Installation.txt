# Data Warehousing - Installation and Environment Setup

## 1. Introduction

A data warehouse can be implemented using local databases, cloud warehouses, or distributed platforms.

For learning, a local PostgreSQL environment is a useful starting point.

## 3. PostgreSQL

Official website:

https://www.postgresql.org/

PostgreSQL can be used to practice:

- SQL
- Data modeling
- Tables
- Views
- Indexes
- Transactions

## 4. PostgreSQL Tools

Useful tools include:

```text
psql
pgAdmin
```

## 5. Verify PostgreSQL

Open terminal:

```bash
psql --version
```

## 6. Connect to PostgreSQL

Example:

```bash
psql -U postgres
```

## 7. Create Database

```sql
CREATE DATABASE datawarehouse;
```

## 8. Connect

```sql
\c datawarehouse
```

## 9. Create Schema

```sql
CREATE SCHEMA warehouse;
```

## 10. Create Dimension

```sql
CREATE TABLE warehouse.dim_date (
    date_key INT PRIMARY KEY,
    full_date DATE NOT NULL,
    year INT,
    month INT,
    day INT
);
```

## 11. Create Vehicle Dimension

```sql
CREATE TABLE warehouse.dim_vehicle (
    vehicle_key SERIAL PRIMARY KEY,
    vehicle_id VARCHAR(50),
    model VARCHAR(100),
    brand VARCHAR(100),
    fuel_type VARCHAR(50)
);
```

## 12. Create Fact Table

```sql
CREATE TABLE warehouse.fact_sales (
    sale_key SERIAL PRIMARY KEY,
    date_key INT,
    vehicle_key INT,
    quantity INT,
    amount DECIMAL(14,2)
);
```

```bash

```

## 19. Requirements

Create:

```text
requirements.txt
```

Example:

```text
pandas
sqlalchemy
psycopg2-binary
```

Install:

```bash
pip install -r requirements.txt
```

## 20. Docker Option

A warehouse environment can also use Docker.

Example PostgreSQL container:

```bash
docker run --name warehouse-postgres ^
-e POSTGRES_PASSWORD=postgres ^
-p 5432:5432 ^
-d postgres
```

## 21. Verify Container

```bash
docker ps
```
