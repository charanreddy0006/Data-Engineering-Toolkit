# Data Warehousing - Cheat Sheet

## 1. Core Definition

A data warehouse is an analytical data platform designed to integrate, store, and query historical business data.

## 2. Main Purpose

```text
Operational Data
      |
      v
Integration
      |
      v
Historical Analytical Data
      |
      v
Reporting
```

## 3. OLTP

```text
Online Transaction Processing

Used for:
- Orders
- Payments
- Registrations
- Service bookings
```

## 4. OLAP

```text
Online Analytical Processing

Used for:
- Reporting
- Dashboards
- Trends
- Aggregations
```

## 5. OLTP vs OLAP

| OLTP | OLAP |
|---|---|
| Transactions | Analytics |
| Current data | Historical data |
| Many writes | Mostly reads |
| Normalized | Dimensional |
| Small queries | Large queries |

## 10. Fact Table

Contains:

- Measures
- Foreign keys
- Business events

Example:

```text
fact_sales
```

## 11. Dimension Table

Contains descriptive attributes.

Examples:

```text
dim_customer
dim_vehicle
dim_product
dim_date
```

## 12. Star Schema

```text
        dim_customer
             |
dim_vehicle--fact_sales--dim_date
             |
         dim_dealer
```

## 13. Snowflake Schema

Dimensions are normalized into additional related tables.

## 14. Grain

Grain = meaning of one fact row.

Example:

```text
One row = One vehicle sale
```

## 15. Surrogate Key

Warehouse-generated key.

```text
customer_key = 1001
```

## 16. Natural Key

Source-system identifier.

```text
customer_id = C001
```

## 17. SCD Type 1

Overwrite old value.

```text
Rajkot
  |
  v
Ahmedabad
```

## 18. SCD Type 2

Preserve history.

```text
Rajkot      2025-2026
Ahmedabad   2026-
```

## 19. Data Mart

```text

 |

 +-- Finance
 +-- Marketing
 +-- Service
```

## 20. Data Lake

Stores large amounts of raw and processed data.

## 21. Lakehouse

Combines lake storage with warehouse-style analytics.

## 22. Partitioning

Divide data into logical sections.

```text
year=2026
month=08
day=11
```

## 23. Partition Pruning

Read only relevant partitions.

## 24. Clustering

Organize data around commonly used columns to improve data skipping or query efficiency, depending on the platform.

## 25. Index

Data structure used to speed up supported query patterns.

## 26. Materialized View

Stores query results physically for faster access.

## 27. Columnar Storage

Stores data by column.

Good for analytical workloads.

```sql

    category,
    SUM(amount)

GROUP BY category;
```

## 63. Filtering

```sql

FROM sales
WHERE sale_date >= '2026-01-01';
```

## 64. Join

```sql
SELECT
    f.amount,
    d.vehicle_model
FROM fact_sales f
JOIN dim_vehicle d
    ON f.vehicle_key = d.vehicle_key;
```

## 65. Window Function

```sql
SELECT
    vehicle_id,
    amount,
    RANK() OVER (
        ORDER BY amount DESC
    ) AS rank
FROM sales;
```
