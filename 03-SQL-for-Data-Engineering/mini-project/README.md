# 🚗 Vehicle Sales Management System

## 📖 Project Overview

This mini project demonstrates how SQL is used to manage and analyze vehicle sales data.

The project uses three related tables:

- Customers
- Vehicles
- Orders

Using SQL, you'll learn how to:

- Create databases
- Create tables
- Insert records
- Retrieve data
- Join multiple tables
- Perform aggregations
- Generate business reports
