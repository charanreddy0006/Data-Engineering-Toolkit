# Installing PostgreSQL

## 📖 Introduction

PostgreSQL is a powerful, open-source relational database widely used in Data Engineering for storing and managing structured data.

---

## 🎯 Requirements

Install:

- PostgreSQL
- pgAdmin 4
- VS Code
- SQLTools Extension (Optional)

---

## Installation Steps

1. Download PostgreSQL.
2. Run the installer.
3. Select pgAdmin.
4. Set a password.
5. Complete the installation.

---

## Verify Installation

Open **SQL Shell (psql)**

```sql
SELECT version();
```

---

## Useful Commands

List Databases

```sql
\l
```

Connect Database

```sql
\c database_name
```

List Tables

```sql
\dt
```

Exit

```sql
\q
```
