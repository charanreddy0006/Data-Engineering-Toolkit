# Common Data Engineering Terms

## 📖 Introduction

Data Engineering includes many technical terms that every beginner should understand. These terms appear frequently in documentation, interviews, and real-world projects.

---

## 🎯 Learning Objectives

- Learn common Data Engineering terminology.
- Understand key concepts.
- Build a strong technical vocabulary.

---

## 📚 Important Terms

| Term | Meaning |
|------|---------|
| ETL | Extract, Transform, Load |
| ELT | Extract, Load, Transform |
| Data Lake | Stores raw data |
| Data Warehouse | Stores processed data |
| Pipeline | Flow of data between systems |
| Metadata | Information about data |
| Schema | Structure of a database |
| Partition | Dividing data into smaller parts |
| Cluster | Group of connected machines |
| Node | A single machine in a cluster |
| Scalability | Ability to handle more data |
| Latency | Delay in processing |
| Throughput | Amount of data processed |
| Data Quality | Accuracy and consistency of data |
| Orchestration | Managing workflow execution |

---

## 🌍 Real-World Example

A company receives customer orders through APIs.

The pipeline:

API → ETL → Data Lake → Spark → Warehouse → Dashboard

Each stage uses the terms explained above.

---

## 🚗 Automobile Industry Example

A connected vehicle continuously sends telemetry data.

The data is partitioned, stored in a Data Lake, processed using Spark, and visualized on dashboards for fleet monitoring.

---

## 💡 Key Takeaways

- Learn these terms before using advanced tools.
- They are common in interviews.
- They help understand Data Engineering architecture.
