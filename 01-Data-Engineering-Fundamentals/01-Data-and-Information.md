# Data and Information

## 📖 Introduction

Data is the foundation of Data Engineering. Every report, dashboard, machine learning model, and business decision begins with data. However, raw data alone has little value until it is processed and transformed into meaningful information.

Understanding the difference between **data** and **information** is the first step toward becoming a Data Engineer.

---

## 🎯 Learning Objectives

After completing this chapter, you will:

- Understand what data is.
- Learn the difference between data and information.
- Identify different types of data.
- Understand why data is valuable.

---

## 📌 What is Data?

Data is a collection of raw facts, observations, or measurements that have not yet been processed.

Examples:

- 25
- Tesla
- 85 km/h
- 2026-08-05

By themselves, these values do not provide meaningful insights.

---

## 📌 What is Information?

Information is processed and organized data that provides meaning and supports decision-making.

Example:

> "The average speed of Tesla vehicles in Hyderabad today is **85 km/h**."

This statement is useful because the raw data has been analyzed.

---

## 📊 Data vs Information

| Data | Information |
|------|-------------|
| Raw facts | Processed data |
| No context | Meaningful context |
| Difficult to understand | Easy to understand |
| Used as input | Used for decisions |

---

## 📂 Types of Data

### Structured Data

Stored in rows and columns.

Examples:

- Employee Records
- Customer Database
- Banking Transactions

---

### Semi-Structured Data

Partially organized data.

Examples:

- JSON
- XML
- Log Files

---

### Unstructured Data

No predefined format.

Examples:

- Images
- Videos
- Audio
- PDF Files
- Emails

---

## 🌍 Real-World Example

A shopping website records:

- Customer Name
- Product
- Price
- Payment Method

These records are raw data.

When sales reports are generated showing the "Top Selling Products," the data becomes information.

---

## 🚗 Automobile Industry Example

A vehicle continuously sends:

- Speed
- GPS Location
- Fuel Level
- Engine Temperature

These are raw data.

A dashboard showing:

> "Vehicle A requires maintenance within 3 days."

is information created after processing the raw data.

---

## 💡 Key Takeaways

- Data is raw.
- Information is processed data.
- Information supports business decisions.
- Data Engineering converts raw data into useful information.
