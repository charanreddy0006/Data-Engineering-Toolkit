# Data Storage Concepts

## 📖 Introduction

Data storage is a fundamental part of Data Engineering. After collecting data from various sources, it must be stored efficiently so it can be processed, analyzed, and retrieved whenever needed.

Choosing the right storage solution depends on the type, volume, and usage of the data.

---

## 🎯 Learning Objectives

After completing this chapter, you will:

- Understand data storage concepts.
- Learn different storage systems.
- Know when to use each storage type.

---

## 📂 Types of Data Storage

### Relational Databases

Examples:

- PostgreSQL
- MySQL
- SQL Server

Best for:

- Structured Data
- Transactions

---

### NoSQL Databases

Examples:

- MongoDB
- Cassandra
- Redis

Best for:

- Flexible schemas
- Large-scale applications

---

### Data Warehouse

Stores processed and structured data for reporting.

Examples:

- Snowflake
- BigQuery
- Amazon Redshift

---

### Data Lake

Stores raw structured and unstructured data.

Examples:

- Amazon S3
- Azure Data Lake
- Hadoop HDFS

---

## 🚗 Automobile Industry Example

Vehicle sensor data is stored in a Data Lake, while processed sales reports are stored in a Data Warehouse for business analysis.

---

## 💡 Key Takeaways

- Different storage systems serve different purposes.
- Data Lakes store raw data.
- Data Warehouses store processed data.
