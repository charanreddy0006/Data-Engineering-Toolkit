# Fundamentals Mini Project

## 🚀 Project Title

Vehicle Sales Data Pipeline

---

## 📖 Objective

Build a simple data pipeline that reads vehicle sales data, processes it, stores it in a database, and generates a summary report.

---

## 🛠 Technologies

- Python
- CSV
- PostgreSQL
- SQL
- Git

---

## 📂 Workflow

```text
CSV File
     │
     ▼
Python Script
     │
     ▼
Data Cleaning
     │
     ▼
PostgreSQL
     │
     ▼
Sales Report
```

---

## 📋 Tasks

- Read CSV data
- Remove duplicate records
- Handle missing values
- Store cleaned data
- Generate sales summary

---

## 📊 Expected Output

The project should display:

- Total Vehicles Sold
- Total Revenue
- Most Popular Brand
- Highest Selling Model

---

## 🚗 Sample Dataset

| Vehicle | Brand | Price |
|----------|--------|--------|
| Nexon | Tata | 1500000 |
| Creta | Hyundai | 1800000 |
| XUV700 | Mahindra | 2200000 |

## 🎯 Skills Practiced

- Data Cleaning
- Data Storage

- Reporting

---

## 💡 Key Takeaways

- Understand the complete data flow.
- Apply Data Engineering fundamentals.
- Prepare for larger end-to-end projects.

## 📝 Summary

This mini project combines the concepts learned in this module and demonstrates how a simple Data Engineering pipeline works from data collection to reporting.
