# Linux for Data Engineering

Linux is a fundamental technology in modern Data Engineering.

Most production data platforms, cloud servers, distributed processing systems, databases, containers, and orchestration platforms run on Linux-based environments.

This module focuses on the practical Linux skills required by Data Engineers.

## Learning Objectives

By completing this module, you will learn:

- Linux fundamentals
- Linux filesystem
- Essential commands
- File and directory management
- Permissions
- Users and groups
- Processes
- Environment variables
- Package management
- Text processing
- grep, sed, and awk
- SSH
- Cron jobs
- Bash scripting
- Linux-based data pipeline automation
- Logging and monitoring
