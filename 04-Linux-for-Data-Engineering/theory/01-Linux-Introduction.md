# Linux Introduction

## Introduction

Linux is an open-source operating system widely used in servers, cloud platforms, containers, databases, and distributed computing systems.

For Data Engineers, Linux is important because many data technologies are deployed and operated in Linux environments.

Examples include:

- Apache Spark
- Apache Kafka
- Apache Airflow
- Hadoop
- PostgreSQL
- Docker
- Kubernetes

## Why Linux?

Linux provides:

- Stability
- Security
- Performance
- Automation
- Powerful command-line tools
- Excellent server support
