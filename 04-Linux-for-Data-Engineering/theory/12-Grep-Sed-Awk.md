# grep, sed and awk

## Introduction

`grep`, `sed`, and `awk` are three extremely useful Linux tools for processing text and structured data.

They are frequently used in:

- Log analysis
- Data cleaning
- ETL scripts
- Server administration
- CSV processing
- Pipeline troubleshooting

---

# grep

`grep` searches for text patterns.

Basic example:

```bash
grep "ERROR" pipeline.log
