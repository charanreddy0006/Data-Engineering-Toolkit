# Linux Filesystem

## Introduction

The Linux filesystem organizes files and directories in a hierarchical structure.

Unlike Windows, Linux uses `/` as the root of the filesystem.

## Basic Structure

```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── opt
├── tmp
├── usr
└── var
