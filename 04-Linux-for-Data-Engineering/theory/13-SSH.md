# SSH

## Introduction

SSH stands for **Secure Shell**.

It allows you to securely connect to and manage remote Linux machines over a network.

Data Engineers frequently use SSH to access:

- Cloud servers
- Data processing machines
- Database servers
- Hadoop clusters
- Airflow servers
- Development environments

---

```bash
ssh username@hostname
