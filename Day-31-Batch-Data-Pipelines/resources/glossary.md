# Batch Pipeline Glossary

**Batch:** Processing records in groups.

**Watermark:** Boundary of successfully processed source data.

**Incremental Load:** Processing new or changed data.

**Full Load:** Processing the complete source dataset.

**CDC:** Capturing source inserts, updates and deletes.

**Idempotency:** Safe repeated execution.

**Backfill:** Historical reprocessing.

**Partition:** Logical subset of data.

**Checkpoint:** Persisted progress.

**Reconciliation:** Comparing source and target results.
