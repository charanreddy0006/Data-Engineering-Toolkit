# Batch Tooling Map

```text
Orchestration
 → Airflow / Dagster / Managed Workflows

Processing
 → Spark / SQL / Python

Storage
 → Object Storage / Warehouse / Lakehouse

Formats
 → Parquet / Avro / JSON / CSV

Quality
 → SQL Tests / dbt Tests / Data Quality Tools

Monitoring
 → Metrics / Logs / Alerts

Deployment
 → Docker / CI/CD / Kubernetes / Cloud
```

Each tool solves a different responsibility. A good architecture composes tools rather than forcing one product to solve everything.
