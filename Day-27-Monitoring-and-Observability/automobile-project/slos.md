# Automotive Data Product SLOs

Define product-specific SLIs and objectives.

| SLI | Measurement |
|---|---|
| Freshness | age of newest expected data |
| Ingestion success | accepted / expected events |
| Valid telemetry | valid / received events |
| Product availability | successful publication windows |
| Processing latency | event-to-product delay |

Targets must be based on actual consumer requirements and documented measurement
boundaries.
