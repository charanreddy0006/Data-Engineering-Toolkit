# Monitoring and Observability Cheat Sheet

```text
OBSERVABILITY
Metrics + Logs + Traces + Context

GOLDEN SIGNALS
Latency + Traffic + Errors + Saturation

DATA SIGNALS
Freshness + Volume + Schema + Distribution + Quality + Lineage

ALERT
Signal + Condition + Severity + Impact + Owner + Runbook

INCIDENT
Detect → Triage → Scope → Diagnose → Mitigate → Validate → Learn

RELIABILITY
SLI = Measurement
SLO = Target
SLA = Formal Commitment
Error Budget = Allowed unreliability

AUTOMOTIVE
Vehicle → Gateway → Kafka → Processing → Lakehouse → Product
```
