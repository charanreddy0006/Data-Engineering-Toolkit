# Platform Monitoring

## Airflow

Monitor:
- DAG success/failure
- task duration
- retries
- scheduling delay
- queued tasks
- executor health

A successful task does not prove that its output is correct.

## Kafka

Monitor:
- consumer lag
- throughput
- broker health
- partition distribution
- errors
- request latency
- replication health

## Spark

Monitor:
- job/stage duration
- failed tasks
- executor utilization
- input/output
- shuffle behavior
- failed stages

## Databases

Monitor:
- connections
- query latency
- locks
- errors
- CPU/memory
- storage
- replication lag
- slow queries

## Kubernetes

Monitor:
- pod restarts
- CPU/memory
- readiness/liveness
- scheduling
- node capacity
- workload status
