# Data Vault vs Dimensional

Data Vault:

- integration-oriented;
- historical;
- auditable;
- source-change tolerant.

Dimensional:

- consumption-oriented;
- BI-friendly;
- business-process focused;
- straightforward for analysts.

A platform may use:

```text
Sources -> Data Vault -> Dimensional marts
```

They can be complementary rather than mutually exclusive.
