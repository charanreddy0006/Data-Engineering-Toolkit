# Setting Up Python

## 📖 Introduction

Before writing Python programs, you need a proper development environment. A typical setup includes Python, VS Code, Git, and a package manager like pip.

---

## 🎯 Requirements

Install:

- Python 3.x
- Visual Studio Code
- Git
- Python Extension for VS Code

---

## 🔧 Verify Installation

Open the terminal and run:

```bash
python --version
```

or

```bash
python3 --version
```

Check pip:

```bash
pip --version
```

---

## 📦 Install a Package

```bash
pip install pandas
```

List installed packages:

```bash
pip list
```

Upgrade pip:

```bash
python -m pip install --upgrade pip
```

---

## 💻 First Python Program

```python
print("Hello, Data Engineering!")
```

Run:

```bash
python hello.py
```
