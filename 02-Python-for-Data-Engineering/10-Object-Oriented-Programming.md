# Object-Oriented Programming

## 📖 Introduction

Object-Oriented Programming (OOP) organizes code using classes and objects. Large Data Engineering projects often use OOP for better code structure and reusability.

---

## 🎯 Learning Objectives

- Understand classes
- Create objects
- Use constructors
- Learn methods

---

## Class Example

```python
class Car:

    def __init__(self, brand):
        self.brand = brand

    def display(self):
        print(self.brand)

car = Car("Tesla")
car.display()
```
