# Control Flow

## 📖 Introduction

Control Flow determines how a program executes based on conditions and loops. It enables Python programs to make decisions and repeat tasks automatically.

---

## 🎯 Topics Covered

- if
- if-else
- elif
- for loop
- while loop
- break
- continue

---

## if Statement

```python
age = 20

if age >= 18:
    print("Eligible")
```

---

## if-else

```python
marks = 40

if marks >= 35:
    print("Pass")
else:
    print("Fail")
```

---

## for Loop

```python
for i in range(5):
    print(i)
```

---

## while Loop

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

---

## break & continue

```python
for i in range(10):

    if i == 5:
        break

    print(i)
```

---

## 🚗 Automobile Example

```python
speed = 95

if speed > 80:
    print("Overspeed Alert")
```

---

## 💡 Key Takeaways

- if makes decisions.
- Loops automate repetitive tasks.
- break exits a loop.
- continue skips an iteration.
