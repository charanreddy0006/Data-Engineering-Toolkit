# Operators in Python

## 📖 Introduction

Operators are symbols that perform operations on variables and values. They are essential for calculations, comparisons, and decision-making in Python programs.

---

## 🎯 Types of Operators

### Arithmetic Operators

| Operator | Example |
|----------|---------|
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Modulus |
| // | Floor Division |
| ** | Power |

Example:

```python
a = 20
b = 5

print(a + b)
print(a * b)
print(a / b)
```

---

### Comparison Operators

```python
print(10 > 5)
print(10 == 5)
print(10 != 5)
```

Returns **True** or **False**.

---

### Logical Operators

- and
- or
- not

Example:

```python
age = 22

print(age > 18 and age < 30)
```

---

### Assignment Operators

```python
x = 10
x += 5
print(x)
```

---

## 🚗 Automobile Example

```python
speed = 90

print(speed > 80)
```

This can be used to detect overspeeding vehicles.

---

## 💡 Key Takeaways

- Operators manipulate data.
- Comparison operators return Boolean values.
- Logical operators combine conditions.
