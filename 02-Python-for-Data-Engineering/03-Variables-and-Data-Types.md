# Variables and Data Types

## 📖 Introduction

Variables store values in memory, while data types define the kind of data a variable can hold. Every Python program relies on variables to process and manipulate information.

---

## 🎯 Common Data Types

| Type | Example |
|------|---------|
| int | 100 |
| float | 45.7 |
| str | "Python" |
| bool | True |
| list | [1,2,3] |
| tuple | (1,2,3) |
| dict | {"name":"Tesla"} |
| set | {1,2,3} |

---

## 💻 Example

```python
name = "Tesla"
price = 3500000
rating = 4.8
electric = True

print(name)
print(price)
```

---

## 📌 Naming Rules

- Use meaningful names
- Start with letters or `_`
- Avoid keywords
- Use snake_case

Example:

```python
vehicle_name = "Nexon EV"
battery_capacity = 40
```

---

## 🚗 Automobile Example

```python
car = "Hyundai Creta"
speed = 85
fuel = 65.4

print(car)
print(speed)
print(fuel)
```

---

## 💡 Key Takeaways

- Variables store data.
- Python supports multiple data types.
- Meaningful variable names improve readability.
