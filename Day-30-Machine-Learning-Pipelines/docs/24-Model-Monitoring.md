# 24. Model Monitoring

Monitor four layers.

## System
- latency
- availability
- errors
- resource usage

## Data
- freshness
- null rate
- schema
- distributions

## Model
- prediction distribution
- performance
- calibration where relevant

## Business
- alert rate
- successful interventions
- outcome quality

## Automobile

If high-risk vehicle predictions jump from 5% to 40%, investigate data, features, model and business changes before concluding the fleet has suddenly become unhealthy.
