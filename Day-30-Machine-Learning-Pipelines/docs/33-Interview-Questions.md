# 33. Interview Questions

## Beginner

1. What is an ML pipeline?
2. Why automate model training?
3. Training vs inference?
4. Batch inference?
5. Online inference?
6. Why validate data?
7. What is a model registry?
8. What is experiment tracking?

## Intermediate

1. How do you prevent training-serving skew?
2. What should be versioned?
3. How do you handle rollback?
4. How do you monitor data drift?
5. How do features fit into the pipeline?
6. Why use orchestration?
7. What makes an ML pipeline reproducible?

## Advanced

1. Design an ML pipeline for millions of vehicles.
2. How do you guarantee point-in-time correctness?
3. How do you handle delayed labels?
4. How do you deploy low-latency inference?
5. How do you prevent bad retraining deployments?

## Scenario

High-risk maintenance predictions suddenly double.

Investigate:
- source data
- feature freshness
- feature distribution
- preprocessing
- model version
- threshold
- deployment
- genuine business change
