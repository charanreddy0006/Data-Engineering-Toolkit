# 29. Security and Governance

## Security

- identity
- authentication
- authorization
- encryption
- secret management
- network controls
- audit logs

## Governance

Track:
- model owner
- intended use
- data sources
- features
- evaluation
- limitations
- approvals
- deployment history

## Automobile

Potentially sensitive data may include precise location, customer-linked records and driving behavior.

Access should follow organizational policy and legitimate business requirements.

## Principle

Security and governance belong in the pipeline design, not only after deployment.
