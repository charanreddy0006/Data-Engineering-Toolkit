# Model Card

## Model
maintenance-risk-v1

## Objective
Predict service requirement within seven days.

## Inputs
Vehicle health and service-history features.

## Output
Risk score.

## Evaluation
Record agreed holdout precision, recall and F1.

## Limitations
Performance can change when vehicle composition, sensor behavior, maintenance processes or source data changes.

## Governance
Production usage requires validation, ownership and monitoring.
