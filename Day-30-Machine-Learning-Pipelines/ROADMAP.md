# Day 30 Roadmap — Machine Learning Pipelines

## Phase 1
Fundamentals, lifecycle, training and inference.

## Phase 2
Data ingestion, validation, preprocessing and feature engineering.

## Phase 3
Datasets, experiments, model training, evaluation and registry.

## Phase 4
Batch inference, online inference, APIs, containers and orchestration.

## Phase 5
CI/CD, reproducibility, monitoring, drift, retraining and rollback.

## Phase 6
Security, governance, automobile architecture and capstone.

## Final Outcome
Design an end-to-end ML system that connects data engineering, feature engineering, model development and production operations.
