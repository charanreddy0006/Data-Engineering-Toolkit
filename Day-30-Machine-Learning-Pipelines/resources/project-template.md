# ML Project Template

## Problem
Define the measurable business objective.

## Data
List sources, history, labels and freshness.

## Features
List feature definitions and time windows.

## Training
Document algorithm, configuration and validation split.

## Evaluation
Define relevant metrics and release gates.

## Serving
Choose batch or online inference.

## Monitoring
Define data, system, model and business signals.

## Retraining
Document schedules and triggers.

## Recovery
Document rollback and incident handling.
