# Tooling Map

```text
Storage
 → S3 / Warehouse / Lakehouse

Transformation
 → SQL / dbt / Spark / Python

Features
 → Feature Store

Experiments
 → MLflow or equivalent

Orchestration
 → Airflow / Kubeflow / Dagster

Serving
 → Batch / API / Managed Platform

Infrastructure
 → Docker / Kubernetes / Cloud

Monitoring
 → Metrics / Logs / Traces / ML Monitoring
```

Tools solve different responsibilities and can be combined according to the architecture.
