# ML Pipeline Glossary

**Pipeline:** Automated sequence of ML/data operations.

**Training:** Process that learns model parameters.

**Inference:** Process that generates predictions.

**Batch Inference:** Scheduled or bulk prediction.

**Online Inference:** Request-driven prediction.

**Model Registry:** Stores model artifacts and lifecycle metadata.

**Experiment Tracking:** Records runs, parameters, datasets and metrics.

**Data Drift:** Change in input-data behavior.

**Model Drift:** Change that degrades model predictive performance.

**Retraining:** Creation of a new candidate model using revised/new data.
