# 31 — Data Lake Limitations

## Governance Complexity

Large lakes require strong metadata and ownership.

## Data Swamps

Poor organization makes data difficult to discover.

## Performance

Raw files can be slower than optimized warehouse tables if poorly designed.

## Small Files

Streaming ingestion may create many tiny objects.

## Security

More data types and users increase security complexity.

## Skill Requirements

Teams may need knowledge of distributed systems, cloud storage, processing,
governance, and observability.

## Cost

Storage may be inexpensive, but uncontrolled processing, scanning, and data
transfer can still become costly.

## Key Point

A data lake is powerful but does not remove the need for data engineering.
