# 41 — Data Lake Cheat Sheet

```text
Data Lake
= scalable storage for diverse data

Raw
= source-preserving data

Processed
= cleaned and standardized data

Curated
= consumer-ready data

Parquet
= columnar analytical file format

Kafka
= event streaming platform

Spark
= distributed processing engine

Catalog
= metadata and dataset discovery

Lineage
= source-to-consumer data path

Governance
= ownership, policies, access, retention

Quality
= accuracy, completeness, consistency, timeliness
```

## Architecture

```text
Source -> Ingestion -> Raw -> Processing -> Curated -> BI/ML
```
