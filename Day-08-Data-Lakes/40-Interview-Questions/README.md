## Scenario

A vehicle company receives millions of telemetry events per hour. Design a
pipeline using Kafka, Spark Streaming, object storage, Parquet, partitioning,
quality checks, monitoring, and curated datasets.

A strong answer should discuss ingestion, storage, processing, reliability,
security, governance, and downstream consumption.
