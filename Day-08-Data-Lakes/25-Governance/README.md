# 25 — Data Governance

Governance ensures that data is trustworthy, discoverable, secure, and used
according to organizational policies.

## Important Areas

- Ownership
- Metadata
- Classification
- Access policies
- Retention
- Privacy
- Lineage
- Quality
- Auditing

## Ownership

Every important dataset should have an accountable owner.

## Classification

Example:

```text
PUBLIC
INTERNAL
CONFIDENTIAL
RESTRICTED
```

## Retention

Organizations should define how long different categories of data are kept.

## Automobile Example

Vehicle identifiers, customer information, GPS data, and service records may
require different access controls and retention policies.

## Principle

Governance should be built into pipelines instead of added after the platform
becomes large.
