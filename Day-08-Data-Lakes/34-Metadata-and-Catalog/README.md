# 34 — Metadata and Data Catalog

## Metadata

Metadata describes data.

Examples:

```text
Dataset name
Owner
Schema
Location
Format
Last updated
Quality score
Classification
```

## Technical Metadata

Describes tables, columns, types, partitions, and storage.

## Business Metadata

Explains business meaning.

Example:

```text
battery_level = percentage of usable battery capacity remaining
```

## Operational Metadata

Tracks freshness, pipeline runs, failures, and update timestamps.

## Catalog

A data catalog allows users to discover datasets and understand what they mean.

## Why It Matters

Without metadata, even perfectly stored data can be practically unusable.
