# 06 — Core Components

## Storage

Stores files and table data.

Examples:

- Amazon S3
- Azure Data Lake Storage
- Google Cloud Storage
- HDFS
- MinIO

## Ingestion

Moves information from sources into the lake.

Examples:

- Kafka
- Apache NiFi
- Airflow
- CDC tools
- APIs

## Processing

Transforms and aggregates data.

Examples:

- Apache Spark
- Apache Flink
- SQL engines
- Python

## File Formats

Common analytical formats include:

- Parquet
- ORC
- Avro

## Metadata

Metadata describes datasets, schemas, ownership, freshness, and location.

## Governance

Governance defines who owns data, who can access it, how long it is retained,
and how sensitive information is handled.

## Monitoring

Monitoring tracks pipeline failures, freshness, volume, quality, and cost.
