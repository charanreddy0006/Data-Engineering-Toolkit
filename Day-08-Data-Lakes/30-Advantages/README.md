# 30 — Advantages of Data Lakes

## Flexibility

Store many data types without forcing every source into one schema immediately.

## Scalability

Object storage can scale to very large data volumes.

## Raw Retention

Historical source data can support future requirements.

## Machine Learning

Raw and detailed data can be used for feature engineering.

## Multiple Consumers

The same platform can support BI, analytics, data science, and ML.

## Cost Model

Object storage can be economical compared with keeping everything in expensive
compute-optimized systems.

## Batch and Streaming

Modern architectures can combine historical and real-time data.

## Automobile Benefit

A manufacturer can combine telemetry, service, warranty, sales, and diagnostic
data in one analytical platform.
